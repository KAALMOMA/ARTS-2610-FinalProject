# ARTS-2610-FinalProject
## Instructions | Unreal Engine 5.6.1
1. Open the Unreal Engine project entitled `final_project_v1`. 
2. To open the scene, navigate to `Content` > `Variant_SideScroller` > `Lvl_SideScrolling`.
3. Double-click this file to open the scene.
4. Press play and have fun!

To activate a lever, press E.
